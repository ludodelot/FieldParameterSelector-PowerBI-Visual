## Ordered FP Selector (Horizontal) v1.0.0.0

Visual separado (GUID propio): convive con el *Ordered FP Selector* vertical en el mismo reporte.

- Cabecera, barra de expandir/contraer y Reset/Clear en una sola línea.
- Orden seleccionado como tira de chips: arrastrar y soltar, o flechas ‹ ›.
- Catálogo por filas: pestaña de área a la izquierda y grupos/chips fluyendo a la derecha.
- Mismos roles de datos, filtro y estado guardado que la v3.2.1.0.

Instalación: Power BI Desktop → Visualizaciones → ⋯ → Importar un objeto visual desde un archivo → seleccionar el `.pbiviz`.

⚠️ Aún no probado en un reporte real de Power BI (revisar sobre todo arrastrar y soltar).
